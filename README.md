# Dehaze Web

Браузерний інструмент для покращення фотографій із туманом і серпанком. Усі фото обробляються локально на пристрої — не відправляються на сервер.

## Режими

- **AUTO Soft**: обережне підвищення локального контрасту.
- **AUTO Strong**: Dark Channel Prior (DCP) з guided-фільтрацією карти прозорості, захистом яскравого неба та контролем підсилення малоконтрастних ділянок.
- **MANUAL**: сила, контраст, гамма, CLAHE, сітка, різкість, захист неба.
- **Порівняння** оригіналу з результатом та експорт у PNG.

Обробка використовує `index.html` і `dehaze-dcp.js`. Обидва файли мають лежати в корені репозиторію.

## Публікація

Сайт публікується через GitHub Pages з GitHub Actions (`.github/workflows/deploy-pages.yml`). За потреби вибрати **Settings → Pages → Source → GitHub Actions**.

Після успішної публікації: https://sergioovcharenko.github.io/Dehaze-Web/

## Обмеження

Алгоритм не відновлює об'єкти, повністю приховані непрозорим туманом. DCP може підсилити шум або створити ореоли в окремих умовах; звіряйте результат з оригіналом. На великих фото обробка в браузері телефона може тривати довше.

## LIVE-відео на сайті (демо)

Угорі є вкладки **Фото / Відео LIVE**. У вкладці відео можна відкрити локальний MP4/WebM або ввімкнути камеру пристрою (HTTPS + дозвіл браузера), натиснути **Антитуман** і змінювати силу GPU-фільтра. Оброблене відео показано **зверху**, оригінал — під ним. Кадри не передаються на сервер.

Поточний LIVE-режим — полегшений однопрохідний WebGL-фільтр локального контрасту й кольорокорекції з захистом світлого неба. **Це не повний фотографічний Multi-scale Fusion / DCP**, що потребує значно більше обчислень. Відображуваний FPS — швидкість рендерингу, не вимірювання наскрізної затримки відеосигналу. Швидкість залежить від GPU, роздільності та браузера.

RTSP з Topotek браузер безпосередньо не відкриє. Для живого мережевого потоку потрібен сумісний браузерний шлюз, а QGroundControl APK потребує окремої інтеграції.

## Офлайн-режим (PWA)

Після першого відкриття сайту **з інтернетом** і успішного кешування Service Worker можна відкрити збережений сайт без мережі. Вкладки Фото і Відео працюють із локальними файлами; камера доступна лише якщо браузер/ОС дозволяють її в цьому режимі. У Safari на iOS натисніть «Поділитися» → «На екран Додому» для запуску як вебдодатка. У Chrome на Android скористайтеся «Встановити додаток» (якщо браузер пропонує). Відео та фотографії користувача **не кешуються сайтом**. Перший запуск, оновлення та мережеві потоки потребують інтернету/локальної мережі.

Після оновлення сайту відкрийте його онлайн щонайменше один раз, щоб оновився офлайн-кеш.
