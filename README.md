# Dehaze Web

Локальний вебдодаток для обробки фотографій із туманом і серпанком.

- AUTO — автоматично оцінює яскравість і контраст фотографії та підбирає параметри.
- MANUAL — сила ефекту, контраст, гамма, локальний контраст CLAHE, різкість.
- Оригінал і результат поруч; збереження у PNG.
- Обробка виконується у браузері без завантаження фотографій на сервер.

## Публікація

Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.

Сайт: https://sergioovcharenko.github.io/Dehaze-Web/

Алгоритм покращує наявні деталі та контраст, а не відновлює об'єкти, повністю приховані туманом. Не використовуйте оброблене фото як єдине джерело для критичних рішень.
